# Sound A4b: ambience asset batch (CC0 beds + one-shots)

Closes #1577. Follow-up to #1500 (A4, PR #1578), which shipped the ambience
mixer with 6/10 one-shots and synth/fake stand-ins for everything else.
This lands the remaining 11 recorded assets - all 7 sampled beds plus the
4 animal one-shots - off Wikimedia Commons since `$FREESOUND_API_KEY` is
still unset.

## Assets (all Wikimedia Commons, ledgered)

Beds (`assets/sound/beds/`): birds, bees, insects (cicada), river,
village_murmur (festival crowd), market_crowd (flea market), fire_crackle.

One-shots (`assets/sound/oneshots/`): sheep_bleat, chicken, dog_bark,
crow (common raven).

Licensing: the two CC0 files enter as `CC0-1.0`; the nine "public domain"
files enter as `unrestricted` + `grant_quote` per the ledger gate, with
the Commons file page as evidence. 11.5 MB of the 20 MB budget used.

## Tooling

- `scripts/sound_fetch_commons.py` (new): Commons CC0/PD fetcher to the
  `_incoming` + sidecar convention - search or `--title`, CC0/PD metadata
  gate, non-Ogg transcode, API backoff/batching, utf-8-safe output.
- `scripts/sound_process.py`: `--license`/`--grant` (honest ledger entries
  for non-CC0 sources, guarded against the allowlist), `--af` pre-filter
  escape hatch (the fire source needed a 1.8 kHz lowpass cascade - its
  +22 dB normalisation turned every crackle into a detector click).
- `game2-audio/examples/clickprobe.rs` (new): click-count probe over any
  decoded asset - the QA loop the batch needed.

## Mixer change

`BED_LEVEL` 0.7 -> 0.84: the constant was calibrated on steady-state
synth/fake beds; real recordings carry dynamics (quiet stretches gate
out of the integrated LUFS), so the real batch needed ~+1.5 dB to hold
the -20±3 LUFS mix bar. All ten scenarios verified inside band with
margin (quiet_village -22.7, market_square -17.4 worst-case headroom
0.44 dB), zero clicks, peaks under -1 dBTP.
