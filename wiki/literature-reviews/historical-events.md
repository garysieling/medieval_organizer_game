## Summary

Medieval Europe experienced recurring crises that shaped societies profoundly: the Great Famine (1315-1317) killed millions through crop failure, the Black Death (1347-1351) eliminated 30-60% of the population, and invasions by Vikings and Mongols devastated regions. These events were not random but followed statistical patterns (Poisson processes) and cascaded through interconnected systems (famine → disease → social unrest). Medieval technological innovations like the three-field system and windmills transformed agriculture. This research provides mechanics for dynamic historical events, disaster cascades, technological progress, and crisis recovery.

### The Black Death (1347-1351)
**Rating:** A+
**Type:** Pandemic Study / Historical Research
**Relevance:** High - Plague mechanics, population shock

**Key Findings:**

**Scale:**
- **Mortality:** 30-60% of Europe's population
- **Global:** 75-200 million deaths total
- **Speed:** Spread across Europe in ~4 years
- **Recurrence:** Returned periodically for centuries

**Transmission:**
- Trade routes (originated in Central Asia)
- Rats and fleas vectors (bubonic form)
- Pneumonic form (human-to-human airborne)
- Port cities hit first, then inland

**Symptoms & Timeline:**
- Bubonic: Buboes (swellings), fever, death in 2-7 days
- Pneumonic: Respiratory, faster death (1-3 days)
- Septicemic: Blood infection, nearly 100% fatal

**Social Responses:**

**Flight:**
- Wealthy fled cities to countryside (often carrying plague with them)
- Quarantine attempts (mostly failed)
- Trade embargoes

**Scapegoating:**
- Jews blamed, pogroms
- Strangers attacked
- "Bad air" theory → bonfires, perfumes

**Religious:**
- Flagellants (self-whipping processions)
- Increased church donations (buying salvation)
- Also: Questioning God's plan

**Economic Effects:**
- **Labor Shortage:** Surviving peasants demanded higher wages
- **Sumptuary Laws:** Attempted to prevent lower classes from dressing above station (failed)
- **Land Abandonment:** Entire villages emptied
- **Feudalism Decline:** Lords couldn't enforce old obligations

**Long-Term:**
- Social mobility increased
- Peasant revolts (1381 in England)
- Art became more morbid (danse macabre, memento mori)
- Medical knowledge slowly advanced

**Source Quality:** Extensive historical documentation, scientific analysis
**Game Application:** Pandemic system with transmission, mortality, and social upheaval

### Poisson Processes for Rare Disaster Modeling
**Rating:** A+
**Type:** Statistical/Mathematical Modeling
**Relevance:** High - Event frequency mechanics

**Key Findings:**

**Poisson Distribution Basics:**
- Models rare events occurring over fixed intervals
- Only requires average event rate (λ) as parameter
- Formula: `P(k events) = (λ^k * e^-λ) / k!`
- Assumes: Events independent, constant rate

**Applications to Historical Disasters:**

**Event Frequency Parameter:**
```
λ = total_events / time_period

Example:
- Great Famines in England (500-1500): ~10 major events / 1000 years
- λ = 0.01 per year
- P(famine in given year) = ~1%
```

**Natural Disaster Examples:**
- **Earthquakes:** Mean rate 0.35/year, Poisson model statistically valid
- **Tropical Cyclones:** Landfall frequency modeled via Poisson (no trend in historical record)
- **Plague Outbreaks:** Recurring but rare, ~50 year cycles on average (post-Black Death)

**Compound Poisson Processes:**
- Traditional Poisson: Fixed severity
- Compound: Random severity per event
- Better for clustered disasters (cascades)

**Formula:**
```
total_damage = Σ(event_i_severity)
where number of events ~ Poisson(λ)
and severity ~ some distribution (e.g., exponential, lognormal)
```

**Limitations:**
- Assumes independence (but disasters often cluster)
- Assumes constant rate (but climate changes)
- Doesn't capture contagion (plague spreads)

**Source Quality:** Peer-reviewed statistical research, applied disaster modeling
**Game Application:** Event scheduling system with statistical realism

- Disaster preparedness simulation
- Random events reflect real-world probability
- Player actions mitigate (not eliminate) risk

**Event Categories:**

   - "Something happens at turn 50, but what?"
   - Allows pacing without total predictability

2. **Fully Random:**
   - Unpredictable timing and nature
   - Examples: Weather, market crashes, ambushes
   - High replay value, low narrativecontrol

3. **Quasi-Random (State-Dependent):**
   - Probability changes based on game state
   - Example: Flooding probability increases with rainfall
   - More realistic, rewards/punishes player choices

**Design Principles:**

- **Transparency:** Players should understand roughly how rare events are
- **Mitigation:** Give players ways to prepare/respond
- **Cascades:** Events trigger events (more realistic)
- **Meaningful:** Events should matter, not just noise

**Implementation:**
- Random number generators
- Weighted probability tables
- Event chains (if X, then Y more likely)

## Game Mechanic Proposals

### Mechanic 1: Poisson-Based Disaster Calendar
**Academic Basis:** Poisson distribution for rare events, historical disaster frequencies

**Translation:**
- **Core System:**
  - Disasters modeled as Poisson processes
  - Each disaster type has mean rate (λ)
  - Events scheduled probabilistically, not deterministically

- **Disaster Types & Frequencies:**

  ```rust
  struct DisasterType {
      name: String,
      lambda: f32,  // Mean events per year
      severity_distribution: SeverityDist,
  }

  // Historical calibration:
  let disasters = vec![
      DisasterType {
          name: "Great Famine".to_string(),
          lambda: 0.01,  // ~1% per year (once per century average)
          severity_distribution: SeverityDist::Exponential { mean: 0.3 },  // 30% crop loss average
      },
      DisasterType {
          name: "Plague Outbreak".to_string(),
          lambda: 0.02,  // ~2% per year (more frequent than famine, post-Black Death)
          severity_distribution: SeverityDist::Lognormal { median: 0.1, spread: 2.0 },
      },
      DisasterType {
          name: "Bad Harvest".to_string(),
          lambda: 0.20,  // ~20% per year (fairly common)
          severity_distribution: SeverityDist::Uniform { min: 0.1, max: 0.5 },
      },
      DisasterType {
          name: "Viking Raid".to_string(),
          lambda: 0.05,  // ~5% per year (regional)
          severity_distribution: SeverityDist::Bimodal { small: (0.05, 0.7), large: (0.3, 0.3) },
          // Most raids minor, some devastating
      },
  ];
  ```

- **Poisson Sampling:**
  ```rust
  fn sample_disasters_for_year(disaster_types: &[DisasterType], rng: &mut impl Rng) -> Vec<Disaster> {
      let mut disasters = Vec::new();

      for disaster_type in disaster_types {
          // Poisson: P(k events) = (λ^k * e^-λ) / k!
          // Simpler: For small λ, approximate as Bernoulli trial
          if disaster_type.lambda < 0.1 {
              // Bernoulli approximation
              if rng.gen::<f32>() < disaster_type.lambda {
                  let severity = sample_severity(&disaster_type.severity_distribution, rng);
                  disasters.push(Disaster {
                      disaster_type: disaster_type.name.clone(),
                      severity,
                  });
              }
          } else {
              // Full Poisson sampling
              let count = sample_poisson(disaster_type.lambda, rng);
              for _ in 0..count {
                  let severity = sample_severity(&disaster_type.severity_distribution, rng);
                  disasters.push(Disaster {
                      disaster_type: disaster_type.name.clone(),
                      severity,
                  });
              }
          }
      }

      disasters
  }

  fn sample_poisson(lambda: f32, rng: &mut impl Rng) -> usize {
      let l = (-lambda).exp();
      let mut p = 1.0;
      let mut k = 0;

      while p > l {
          k += 1;
          p *= rng.gen::<f32>();
      }

      k - 1
  }
  ```

**Educational Value:** Teaches statistical nature of historical disasters

**Fun Factor:** Unpredictable but not arbitrary, planning for uncertainty

**Implementation:** Statistical event sampling per game year

### Mechanic 2: Cascade System (Event Chains)
**Academic Basis:** Crisis of Late Middle Ages (interconnected failures), compound effects

**Translation:**
- **Core Concept:**
  - Events trigger other events
  - Systems interconnected (agriculture → health → economy → politics)
  - Cascades amplify disasters

- **Cascade Chains:**

  **Example: Famine → Plague Cascade**
  ```
  Bad Weather
    ↓
  Crop Failure (-50% harvest)
    ↓
  Food Shortage
    ↓ (triggers if stores < 3 months)
  Malnutrition (weakened immunity)
    ↓ (+200% disease susceptibility)
  Plague Outbreak (if plague present in region)
    ↓
  Population Loss (-30%)
    ↓
  Labor Shortage
    ↓
  Economic Collapse + Social Unrest
  ```

  **Example: Black Death Full Cascade**
  ```
  Plague Arrives (trade route)
    ↓
  Urban Outbreak (high density)
    ↓ (spreads to connected cities)
  Regional Pandemic
    ↓
  Population Loss (-40%)
    ├─→ Labor Shortage → Wage Increases → Sumptuary Law Violations → Social Mobility
    ├─→ Land Abandonment → Villages Empty → Reclaimed by Forest
    ├─→ Religious Crisis → Church Authority Questioned → Heresies Spread
    ├─→ Scapegoating → Pogroms → Minority Persecution
    └─→ Trade Disruption → Economic Depression → Recovery Takes Decades
  ```

- **Implementation:**
  ```rust
  struct EventCascade {
      trigger: EventType,
      conditions: Vec<Condition>,
      consequences: Vec<(EventType, f32)>,  // (event, probability)
  }

  let famine_cascade = EventCascade {
      trigger: EventType::CropFailure,
      conditions: vec![
          Condition::FoodStores(LessThan(90)),  // Less than 3 months
      ],
      consequences: vec![
          (EventType::Malnutrition, 0.9),  // 90% chance
          (EventType::SocialUnrest, 0.5),  // 50% chance
          (EventType::Migration, 0.3),     // 30% chance (people flee)
      ],
  };

  let plague_cascade = EventCascade {
      trigger: EventType::PlagueOutbreak,
      conditions: vec![],  // Always cascades
      consequences: vec![
          (EventType::PopulationLoss, 1.0),       // Certain
          (EventType::LaborShortage, 0.8),       // If pop loss > 20%
          (EventType::ReligiousCrisis, 0.6),     // People question God
          (EventType::Scapegoating, 0.7),        // Blame minorities
          (EventType::TradeDisruption, 0.9),     // Ports close
      ],
  };

  fn process_cascade(event: &Event, cascades: &[EventCascade], state: &GameState, rng: &mut impl Rng) -> Vec<Event> {
      let mut triggered_events = Vec::new();

      for cascade in cascades.iter().filter(|c| c.trigger == event.event_type) {
          // Check conditions
          if cascade.conditions.iter().all(|cond| cond.is_met(state)) {
              // Trigger consequences probabilistically
              for (consequence_type, probability) in &cascade.consequences {
                  if rng.gen::<f32>() < *probability {
                      triggered_events.push(Event {
                          event_type: consequence_type.clone(),
                          severity: event.severity * 0.8,  // Cascades slightly weaker
                          caused_by: Some(Box::new(event.clone())),
                      });
                  }
              }
          }
      }

      // Recursively process cascades (limited depth to prevent infinite)
      let mut all_events = triggered_events.clone();
      for triggered in &triggered_events {
          let sub_cascades = process_cascade(triggered, cascades, state, rng);
          all_events.extend(sub_cascades);
      }

      all_events
  }
  ```

**Educational Value:** Shows interconnected nature of historical crises

**Fun Factor:** Dramatic escalations, domino effects, player must manage cascades

**Implementation:** Event chain system with conditional triggering

### Mechanic 3: Pandemic Simulation (Black Death-style)
**Academic Basis:** Black Death historical data, epidemic modeling

**Translation:**
- **Transmission Model:**
  - **Spatial:** Spreads via trade routes, proximity
  - **Temporal:** Weeks/months to spread across region
  - **Mortality:** 30-60% in affected areas

- **Disease States:**
  ```rust
  enum DiseaseState {
      Susceptible,
      Exposed { days_remaining: u32 },  // Incubation
      Infected { days_remaining: u32 }, // Contagious
      Recovered,  // Immune
      Dead,
  }

  struct Settlement {
      population: Vec<Person>,
      disease_present: bool,
      quarantine: bool,
  }
  ```

- **Spread Mechanics:**
  ```rust
  fn spread_plague(settlements: &mut [Settlement], trade_network: &TradeNetwork, dt: f32) {
      // Within-settlement spread (high density = faster)
      for settlement in settlements.iter_mut() {
          if !settlement.disease_present {
              continue;
          }

          let density = settlement.population.len() as f32 / settlement.area;
          let infected_count = settlement.population.iter()
              .filter(|p| matches!(p.disease_state, DiseaseState::Infected { .. }))
              .count();

          let base_transmission_rate = 0.3;  // 30% per contact
          let contacts_per_day = density * 0.1;  // More density = more contacts

          for person in &mut settlement.population {
              if matches!(person.disease_state, DiseaseState::Susceptible) {
                  let exposure_chance = 1.0 - (1.0 - base_transmission_rate).powf(
                      infected_count as f32 * contacts_per_day * dt
                  );

                  if rng.gen::<f32>() < exposure_chance {
                      person.disease_state = DiseaseState::Exposed { days_remaining: 3 };
                  }
              }
          }
      }

      // Between-settlement spread (trade routes)
      for (settlement_a, settlement_b, trade_volume) in trade_network.routes() {
          if settlement_a.quarantine || settlement_b.quarantine {
              continue;  // Quarantine blocks trade
          }

          if settlement_a.disease_present && !settlement_b.disease_present {
              let introduction_chance = trade_volume * 0.01;  // 1% per trade unit
              if rng.gen::<f32>() < introduction_chance {
                  settlement_b.disease_present = true;
                  // Introduce disease to random person
                  if let Some(person) = settlement_b.population.iter_mut().next() {
                      person.disease_state = DiseaseState::Exposed { days_remaining: 3 };
                  }
              }
          }
      }
  }

  fn update_disease_progression(person: &mut Person, dt: f32) {
      match &mut person.disease_state {
          DiseaseState::Exposed { days_remaining } => {
              *days_remaining -= dt as u32;
              if *days_remaining == 0 {
                  person.disease_state = DiseaseState::Infected { days_remaining: 7 };
              }
          },
          DiseaseState::Infected { days_remaining } => {
              *days_remaining -= dt as u32;
              if *days_remaining == 0 {
                  // Mortality roll: 40% die, 60% recover
                  if rng.gen::<f32>() < 0.4 {
                      person.disease_state = DiseaseState::Dead;
                  } else {
                      person.disease_state = DiseaseState::Recovered;
                  }
              }
          },
          _ => {}
      }
  }
  ```

- **Player Responses:**
  - **Quarantine:** Block trade (stops spread, hurts economy)
  - **Flight:** Wealthy flee cities (may carry disease)
  - **Prayer:** Religious ceremonies (placebo, increases gathering = spread)
  - **Burn Bodies:** Reduces transmission slightly
  - **Close Gates:** Prevent travelers

**Educational Value:** Teaches epidemic dynamics, tradeoffs in response

**Fun Factor:** Tense decisions, watching spread on map, managing crisis

**Implementation:** SIR-like disease model with spatial component

- **Diffusion Mechanics:**
  ```rust
  fn check_tech_diffusion(village: &Village, neighbors: &[Village], innovations: &[Innovation]) -> Option<Innovation> {
      for innovation in innovations {
          // Has neighbor discovered it?
          let neighbor_has = neighbors.iter().any(|n| n.has_tech(&innovation.name));

          if neighbor_has {
              // Much higher chance if neighbor has it (diffusion)
              let diffusion_chance = 0.20;  // 20% per year from neighbors
              if rng.gen::<f32>() < diffusion_chance {
                  return Some(innovation.clone());
              }
          } else {
              // Independent discovery (rarer)
              if village.year >= innovation.min_year &&
                 innovation.prerequisites.iter().all(|p| p.is_met(village)) &&
                 rng.gen::<f32>() < innovation.chance_per_year {
                  return Some(innovation.clone());
              }
          }
      }

      None
  }
  ```

**Educational Value:** Teaches how technology spreads (diffusion + independent discovery)

**Fun Factor:** Exciting unlock moments, historical progression, neighbor envy

**Implementation:** Event-based tech tree with diffusion mechanics

### Mechanic 5: Invasion and Migration Events
**Academic Basis:** Viking and Mongol invasions, population movements

**Translation:**
- **External Threats:**
  - Invasions originate outside player's control
  - Must respond (flee, fortify, negotiate, resist)

- **Invasion Phases:**

  **Phase 1: Warning**
  - Rumors arrive (neighboring region attacked)
  - Player has time to prepare
  - Options: Build walls, train militia, stockpile food, flee

  **Phase 2: Arrival**
  - Invading force appears
  - Player choices:
    - **Submit:** Pay tribute, avoid destruction (lose resources, autonomy)
    - **Resist:** Fight (may win or lose)
    - **Flee:** Evacuate population (lose infrastructure, save people)
    - **Negotiate:** Try to bargain (requires high diplomacy)

  **Phase 3: Aftermath**
  - **If Conquered:**
    - New overlords (tribute demands)
    - Cultural mixing (technology transfer possible)
    - Resistance movements
  - **If Victorious:**
    - Loot from invaders
    - Reputation boost
    - But: Casualties, damaged infrastructure
  - **If Fled:**
    - Refugee crisis in new location
    - Old village destroyed/occupied
    - Rebuild from scratch

- **Implementation:**
  ```rust
  struct Invasion {
      origin: String,  // "Vikings from North", "Mongol Horde from East"
      strength: f32,   // 0.0-1.0
      arrival_date: Date,
      warning_date: Date,
  }

  enum InvasionResponse {
      Submit,
      Resist,
      Flee,
      Negotiate,
  }

  fn resolve_invasion(invasion: &Invasion, response: InvasionResponse, village_strength: f32) -> InvasionOutcome {
      match response {
          InvasionResponse::Submit => {
              InvasionOutcome::Conquered {
                  tribute_demand: invasion.strength * 100.0,  // Gold per year
                  autonomy_lost: 0.5,  // Can't make all own decisions
                  cultural_influence: Some(invasion.origin.culture),
              }
          },
          InvasionResponse::Resist => {
              let battle_result = simulate_battle(village_strength, invasion.strength);
              if battle_result.victory {
                  InvasionOutcome::Victorious {
                      loot: invasion.strength * 50.0,
                      casualties: battle_result.casualties,
                      reputation: Reputation::DefenderOfRealm,
                  }
              } else {
                  InvasionOutcome::Defeated {
                      population_loss: 0.6,
                      infrastructure_destroyed: 0.8,
                      enslaved: battle_result.survivors * 0.3,
                  }
              }
          },
          InvasionResponse::Flee => {
              InvasionOutcome::Evacuated {
                  population_saved: 0.7,  // 30% casualties in flight
                  infrastructure_lost: 1.0,  // Everything left behind
                  refugee_status: true,
              }
          },
          InvasionResponse::Negotiate => {
              let diplomacy_check = village.diplomacy_skill;
              if rng.gen::<f32>() < diplomacy_check {
                  InvasionOutcome::TreatyNegotiated {
                      tribute_reduced: 0.5,  // Pay half
                      autonomy_retained: 0.8,
                      alliance_possible: true,
                  }
              } else {
                  // Negotiation failed, invasion proceeds
                  resolve_invasion(invasion, InvasionResponse::Resist, village_strength)
              }
          }
      }
  }
  ```

**Educational Value:** Teaches historical vulnerability to external forces, response strategies

**Fun Factor:** High-stakes decisions, asymmetric warfare, diplomatic gameplay

**Implementation:** Event system with branching outcomes based on player choices

## Domain Translation Patterns

### Pattern: Historical Frequencies → Poisson Parameters
**Approach:**
1. Identify historical event counts over time period
2. Calculate λ = events / years
3. Sample Poisson distribution per game year
4. Adjust for game pacing (compress or expand time)

**Example:**
```
# Historical: Great Famines ~once per century in medieval England
# λ = 0.01 per year
# Game: Sample Poisson(0.01) each year
# Result: Rare but plausible famine events
```

---

### Pattern: Crisis Cascades → Event Chains
**Approach:**
1. Identify historical cascade patterns (famine → disease → unrest)
2. Model as conditional probability chains
3. Each event can trigger subsequent events
4. Severity compounds or dampens through chain

**Example:**
```
# Historical: Great Famine → Weakened immunity → Black Death devastation
# Game: CropFailure (if stores<threshold) → Malnutrition → PlagueVulnerability(+200%)
```

---

### Pattern: Pandemic Spread → SIR Model with Geography
**Approach:**
1. Use SIR disease model (Susceptible, Infected, Recovered)
2. Add spatial component (trade routes, distance)
3. Calibrate mortality to historical rates (Black Death = 30-60%)
4. Player interventions modify transmission rate

**Example:**
```
# Historical: Black Death spread via trade, killed 30-60%
# Game: Plague spreads along trade routes, density affects transmission, quarantine reduces spread
```
