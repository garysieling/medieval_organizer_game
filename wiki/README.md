# Game Development Knowledgebase

This wiki serves as a central repository for game development knowledge, resources, and references.

## Structure

- `books/` - Books on game making and development
- `articles/` - Articles and papers on game development
- `artistic-references/` - Artistic references, inspiration, and visual resources
- `software-design/` - Software design patterns, architecture, and best practices

## Usage

Add new knowledge by creating markdown files in the appropriate directories. Each entry should be named descriptively and include relevant information, links, and notes.
