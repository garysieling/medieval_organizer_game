# Medieval Crafts & Tools Literature Review

**Survey Date:** 2026-10-25
**Agent:** Literature Survey Agent
**Confidence:** High
**Domain:** Medieval Crafts, Professional Tools, Artisan Techniques

## Summary

Medieval crafts required specialized tools and deep knowledge passed through apprenticeships. Luthiers built lutes using planes, chisels, mallets, and wood selection (spruce soundboards, maple ribs). Beekeepers used skeps (woven straw basket hives), smoke pots, long knives, and spoon-shaped extractors to harvest honey and wax. Stained glass makers employed grozing irons to shape glass, lead caming for assembly, and painted with silver stain. Stonemasons carved cathedrals using chisels, mallets, hammers, levels, and plumb bobs. This research provides mechanics for craft professions, tool requirements, material selection, and skill progression.

## Key Sources

### Luthier Tools & Instrument Making
**Rating:** A
**Type:** Historical Craft Analysis / Manuscript Evidence
**Relevance:** High - Instrument making profession

**Key Findings:**

**Primary Historical Sources:**
- **Jost Amman's Book of Trades (1560s):** Only surviving picture of lutemaker's workshop
- **Arnaut of Zwolle (mid-15th century):** Manuscript with diagrams for lute construction
- **Marin Mersenne's Harmonie Universelle (1636):** Describes "wooden nails" and shaping forms
- **Thomas Mace's Musick's Monument (1676):** Hot gluing iron, glued paper strips

**Tools Shown in Amman's Workshop:**
- 2 planes
- 2 chisels
- 1 mallet
- 1 gluepot
- 1 bench
- 1 ax and block

**Wood Selection:**

**Soundboard (Top):**
- **Primary:** Spruce (or sometimes pine)
- **Thickness:** As thin as barely 1 mm
- **Selection Criteria:** Resonant qualities, straight grain
- **Acoustic Properties:** Transmits string vibrations efficiently

**Bowl/Body (Ribs):**
- **Common:** Maple, yew
- **Luxury:** Rosewood, ebony, snakewood
- **Construction:** 9 slats/ribs individually shaped and bent, glued together
- **Vaulting:** Creates resonant cavity

**Neck:**
- **Materials:** Lighter woods (cedar, fruitwood)
- **Properties:** Needs strength without excessive weight

**Fingerboard:**
- **Material:** Thin veneer of ebony
- **Properties:** Hardness, smooth surface

**Construction Methods:**

**Rib Shaping:**
- 20-degree wedge glued to lute shape
- Cut out on band saw (or shaped by hand in medieval period)
- Ensures consistency across ribs
- Bent using heat/moisture

**Assembly:**
- "Wooden nails" hold ribs onto form
- Soundboard-shaped piece keeps completed back in shape
- Hot gluing iron for assembly
- Paper strips reinforcement

**Medieval vs Renaissance:**
- Medieval: Small instruments carved from solid block (except large lutes)
- Renaissance: Rib construction becomes standard

**Source Quality:** Primary sources (manuscripts, woodcuts), modern luthier knowledge
**Game Application:** Luthier profession with wood selection and tool requirements

### Beekeeping Tools & Hive Management
**Rating:** A
**Type:** Historical Craft Practice / Agricultural History
**Relevance:** High - Honey and wax production

**Key Findings:**

**Products:**
- **Honey:** Main product, sweetener (sugar rare/expensive)
- **Beeswax:** Candles for religious ceremonies, sealing wax, waterproofing
- **Importance:** Monasteries ardent beekeepers (needed candle wax)

**Hive Types:**

**Skeps (Straw Basket Hives):**
- **Etymology:** Anglo-Saxon "Skeppa" = basket
- **Shape:** Dome-shaped or conical (sugarloaf), bell-shaped variants
- **Size:** Typically 40 cm height
- **Materials:**
  - Rye or wheat straw (8-10 rows)
  - Long straws coil-stitched with blackberry briar
  - Osier (water willow) vertical ties
  - OR wicker (privet, hazel) daubed with "cowcloome" (manure + clay)

- **Construction:** Woven straw coiled into basket, open-end-down
- **Timeline:** Introduced by Saxons after AD 500

**Alternative Hive Types:**
- Wicker with mud/dung daub
- Hollow logs (tree beekeeping)
- Wall cavities

**Tools:**

**1. Smoke Pots/Torches:**
- **Purpose:** Calm bees (reduces aggression)
- **Method:** Smoke introduced into hive before accessing
- **Materials:** Various combustibles

**2. Long Knives:**
- **Purpose:** Slicing off honeycomb
- **Evidence:** Depicted in Exultet rolls (southern Italy)
- **Blade Length:** Long enough to reach deep into hive

**3. Spoon-Shaped Extractors:**
- **Regional:** Iberia, southern France, Italy
- **Method:** Watered so honey slides easily
- **Size:** Large, for scooping comb/honey

**4. Climbing Equipment (Tree Beekeeping):**
- **Poland (Bashkir method):**
  - "Leziwo" = bar used as seat
  - Rope (leather, linen, fiber)

- **Germany (Zeidlerei):**
  - Ladders or seat harnesses
  - Pipes for smoke delivery
  - "Imkerbeil" = specialized beekeeper's ax

**Harvesting Process:**
1. Apply smoke to calm bees
2. Remove top of skep or cut into side
3. Slice honeycomb with long knife
4. Extract honeycomb sections
5. Separate honey from wax (crushing, heating)
6. **Destructive:** Often killed entire colony (skeps non-removable comb)

**Wax Processing:**
- Heat honeycomb to melt wax
- Strain to remove impurities
- Pour into molds
- Use for candles, sealing, waterproofing

**Source Quality:** Historical manuscripts, archaeological evidence, craft continuity
**Game Application:** Beekeeping profession with skep construction and honey/wax harvesting

### Stained Glass Making Tools & Techniques
**Rating:** A+
**Type:** Medieval Craft Documentation / Art Historical Research
**Relevance:** High - Cathedral construction, church decoration

**Key Findings:**

**Tools:**

**1. Red-Hot Iron (Glass Cutting):**
- **Method:** Apply to edge of glass sheet
- **Result:** Thermal shock starts crack
- **Control:** Guide crack along desired path
- **Limitation:** Less precise than later methods

**2. Grozing Iron:**
- **Description:** Notched tool
- **Function:** Crumble away bits of glass from edges
- **Skill:** Can be used with great speed and precision
- **Hallmark:** Medieval panels have close fit of complex, tightly interlocking pieces

**3. Diamond Cutter:**
- **Introduction:** Early 17th century
- **Method:** Score glass with hard stone, break along score
- **Advantage:** More precise than hot iron
- **Medieval:** Not available, but hard stones possibly used

**4. Leading Tools:**
- **Caming:** Lead strips with H-shaped channels
- **Came Knife:** Cut lead to length
- **Soldering Iron:** Join lead at junction points
- **Lathekin:** Tool for pressing glass into lead channels

**Painting Tools:**

**Brushes:**
- **Pre-14th Century:** Regular brushes, sticks, quills, stiff coarse brushes
- **Technique:** "Smear technique" - paint then work into it
- **14th Century Innovation:** Badger hair brushes (more refined appearance)

**Paints:**
- **Color:** Usually black or brown (metal oxide based)
- **Application:** Painted directly onto colored glass
- **Firing:** Heated to fuse paint to glass permanently

**Silver Stain (14th Century Discovery):**
- **Material:** Silver compound applied to glass
- **Firing:** Heats to stain glass
- **Colors:** Pale lemon to deep orange
- **Innovation:** Allows color variation without separate glass piece

**Techniques:**

**1. Design:**
- Create full-size cartoon (drawing)
- Lay glass pieces over cartoon
- Trace design onto glass

**2. Cutting:**
- Hot iron method (score and crack)
- Grozing iron to refine edges
- Close fit essential for structural strength

**3. Painting:**
- Paint details (faces, folds, shading) onto colored glass
- Multiple layers possible
- Each layer fired separately

**4. Silver Staining:**
- Apply silver compound to areas needing yellow/orange
- Fire in kiln
- Chemical reaction stains glass

**5. Leading:**
- Fit glass pieces into lead caming
- Assemble like jigsaw puzzle
- Solder lead joints with tin/lead solder
- Reinforce with iron armature bars (large panels)

**6. Cementing:**
- Force putty between glass and lead
- Waterproofs panel
- Strengthens structure

**Source Quality:** Art historical research, surviving medieval windows, modern glazier knowledge
**Game Application:** Stained glass profession with specialized tools and multi-step process

### Stonemason Tools & Cathedral Building
**Rating:** A
**Type:** Architectural History / Craft Analysis
**Relevance:** High - Construction, sculpture, monuments

**Key Findings:**

**Tools (Similar to Modern):**

**1. Chisels (Multiple Types):**
- **Point Chisel:** Rough work, removing large chunks
- **Flat Chisel:** Broad, flat blade for smoothing surfaces
- **Toothed/Claw Chisel:** Create parallel lines, texture
- **Fine Chisel:** Delicate carving, detail work

**2. Mallets:**
- **Joiner's Mallet:** Flat head, strikes chisels without damage
- **Stonemason's Mallet:** Truncated-cone head, transmits force precisely
- **Wooden:** Won't chip chisel edge (unlike metal hammers)

**3. Hammers:**
- **Mason's Hammer:** Initial rough-hewing
- **Scappling Hammer:** Prepare wall stone, rough shaping
- **Lump-Hammer:** Heavy striking force

**4. Axes:**
- **Purpose:** Hew stone into approximate shape (roughmasons)
- **Technique:** Like woodworking but for soft stone

**5. Measuring/Layout Tools:**
- **Square:** Right angles, layout
- **Compass:** Circles, arcs, geometric design
- **Level:** Ensure horizontal surfaces
- **Plumb Bob:** Verify vertical alignment
- **Measuring Rod:** Standard lengths

**Stonemason Hierarchy:**

**1. Roughmasons/Layers:**
- Prepare wall stone
- Scappling hammers
- Hew with axes
- Lay courses (rows) of stone

**2. Freestone Masons:**
- Work fine stone (limestone, sandstone)
- Mallet and chisel carving
- Create ashlar (precisely cut blocks)
- Architectural elements

**3. Master Masons:**
- Design buildings
- Geometry and mathematics
- Supervise construction
- Guild leaders

**Carving Technique:**

**1. Roughing Out:**
- Point chisel to knock off large portions
- Establish general form
- Remove excess quickly

**2. Shaping:**
- Claw chisel creates parallel lines
- Reveals 3D form
- Texture for later smoothing

**3. Smoothing:**
- Flat chisels remove claw marks
- Surface becomes even
- Preparation for fine detail

**4. Detailing:**
- Fine chisels with shallow strokes
- Wooden mallet for control
- Eyes, hair, clothing folds, ornamentation

**Materials Worked:**
- **Limestone:** Soft, easy to carve
- **Sandstone:** Varies by hardness
- **Marble:** Hard, beautiful finish
- **Granite:** Very hard, difficult (rarely used for carving)

**Cathedral Construction:**
- Multi-generational projects (decades or centuries)
- Complex geometry (arches, vaults, buttresses)
- Precision required for structural stability
- Decorative and structural elements integrated

**Guild System:**
- 7-year apprenticeships
- Trade secrets (geometry, proportion)
- Quality standards
- Wages and working conditions

**Source Quality:** Historical iconography, cathedral records, modern mason comparison
**Game Application:** Stonemason profession with tool progression and skill tiers

  ```rust
  struct InstrumentRecipe {
      instrument_type: InstrumentType,
      soundboard_wood: WoodType,

      tools_required: Vec<Tool>,
      skill_requirement: u8,

      Lute,
      Viol,
      Rebec,
      Harp,

  let lute_recipe = InstrumentRecipe {
      instrument_type: InstrumentType::Lute,
      soundboard_wood: WoodType::Spruce,
      body_wood: WoodType::Maple,  // 9 ribs
      neck_wood: WoodType::Cedar,
      tools_required: vec![
          Tool::Plane,
          Tool::Chisel,
          Tool::Mallet,
          Tool::Gluepot,
          Tool::Knife,
      ],
      skill_requirement: 60,  // Advanced skill
      crafting_time: 45,      // 1.5 months
  };

  fn craft_instrument(recipe: &InstrumentRecipe, luthier_skill: u8, workshop: &LuthierWorkshop) -> CraftResult {
      // Check tools
      if !recipe.tools_required.iter().all(|t| workshop.tools.contains(t)) {
          return CraftResult::MissingTools;
      }

      // Check materials
      let soundboard_needed = 1;
      let ribs_needed = 9;  // For lute
      let neck_needed = 1;

      // Check skill
      if luthier_skill < recipe.skill_requirement {
          return CraftResult::InsufficientSkill;
      }

      // Crafting success
      let quality_roll = rng.gen::<f32>();
      let skill_bonus = (luthier_skill as f32 / 100.0) * 0.5;

      let base_quality = 0.5 + skill_bonus + quality_roll * 0.3;

      // Wood quality affects sound
      let wood_quality = recipe.soundboard_wood.acoustic_quality() * 0.4 +
                         recipe.body_wood.acoustic_quality() * 0.4 +
                         recipe.neck_wood.acoustic_quality() * 0.2;

      let final_quality = (base_quality + wood_quality) / 2.0;

      CraftResult::Success {
          instrument: Instrument {
              instrument_type: recipe.instrument_type,
              sound_quality: final_quality,
              durability: 100,
              value: calculate_value(final_quality, recipe),
          },
          time_taken: recipe.crafting_time,
      }
  }
  ```

**Educational Value:** Teaches instrument construction, wood acoustics

**Fun Factor:** High-value crafting, luxury goods, bard/minstrel support

**Implementation:** Recipe-based crafting with wood selection

  ```rust
  fn harvest_honey(skep: &mut Skep, has_smoke: bool, knife: bool) -> HarvestResult {
      if !has_smoke {
          // Bees aggressive without smoke
          return HarvestResult::Stung { damage: 10 };
      }

      if !knife {
          return HarvestResult::MissingTools;
      }

      // Destructive harvest (medieval method)
      let honey_yield = skep.honey_stored;
      let wax_yield = honey_yield / 5;  // Ratio of wax to honey

      // Colony destroyed or severely weakened
      skep.colony_strength *= 0.2;  // 80% loss
      skep.honey_stored = 0;

      // Chance colony dies entirely
      if rng.gen::<f32>() < 0.5 {
          return HarvestResult::ColonyDied {
              honey_gained: honey_yield,
              wax_gained: wax_yield,
          };
      }

      HarvestResult::Success {
          honey_gained: honey_yield,
          wax_gained: wax_yield,
          colony_weakened: true,
      }
  }
  ```

### Mechanic 3: Stained Glass Making Profession
**Academic Basis:** Medieval glazier tools, techniques, cathedral windows

**Translation:**
- **Profession:** Glazier (Stained Glass Maker)
- **Products:** Stained glass panels (church windows, noble estates)

- **Tools & Materials:**

- **Crafting Process (Multi-Step):**
  ```rust
  struct StainedGlassPanel {
      pieces: Vec<GlassPiece>,
      design_complexity: f32,  // 0.0-1.0
      size: (u32, u32),  // width x height in cm
      value: u32,
  }

  struct GlassPiece {
      color: GlassColor,
      shape: Shape,
      painted_details: bool,
      silver_stained: bool,
  }

  // Step 1: Design
  fn create_cartoon(complexity: f32, artist_skill: u8) -> DesignResult {
      let success_chance = (artist_skill as f32 / 100.0) + (1.0 - complexity) * 0.3;

      if rng.gen::<f32>() < success_chance {
          DesignResult::Success {
              design: Design { complexity },
          }
      } else {
          DesignResult::Failed
      }
  }

  // Step 2: Cut Glass
  fn cut_glass_piece(color: GlassColor, shape: Shape, has_iron: bool, has_grozing_iron: bool, skill: u8) -> CutResult {
      if !has_iron || !has_grozing_iron {
          return CutResult::MissingTools;
      }

      // Cutting difficulty based on shape complexity
      let difficulty = shape.complexity();
      let success_chance = (skill as f32 / 100.0) * (1.0 - difficulty * 0.5);

      if rng.gen::<f32>() < success_chance {
          CutResult::Success {
              piece: GlassPiece {
                  color,
                  shape,
                  painted_details: false,
                  silver_stained: false,
              },
          }
      } else {
          CutResult::Broken  // Glass broke, wasted
      }
  }

  // Step 3: Paint (Optional)
  fn paint_glass_piece(piece: &mut GlassPiece, has_brushes: bool, has_kiln: bool, skill: u8) -> PaintResult {
      if !has_brushes || !has_kiln {
          return PaintResult::MissingTools;
      }

      // Painting success
      let success_chance = skill as f32 / 100.0;

      if rng.gen::<f32>() < success_chance {
          piece.painted_details = true;
          // Must fire in kiln
          PaintResult::Success
      } else {
          PaintResult::Smudged  // Ruined, must clean and retry
      }
  }

  // Step 4: Silver Stain (Optional, 14th century+)
  fn apply_silver_stain(piece: &mut GlassPiece, has_silver_stain: bool, has_kiln: bool) -> StainResult {
      if !has_silver_stain || !has_kiln {
          return StainResult::MissingMaterials;
      }

      piece.silver_stained = true;
      // Fires to yellow/orange
      StainResult::Success
  }

  // Step 5: Lead and Assemble
  fn assemble_panel(pieces: Vec<GlassPiece>, has_lead: bool, has_soldering_iron: bool, skill: u8) -> AssemblyResult {
      if !has_lead || !has_soldering_iron {
          return AssemblyResult::MissingTools;
      }

      let assembly_difficulty = pieces.len() as f32 / 100.0;  // More pieces = harder
      let success_chance = (skill as f32 / 100.0) * (1.0 - assembly_difficulty * 0.3);

      if rng.gen::<f32>() < success_chance {
          AssemblyResult::Success {
              panel: StainedGlassPanel {
                  pieces,
                  design_complexity: calculate_complexity(&pieces),
                  size: calculate_size(&pieces),
                  value: calculate_value(&pieces),
              },
          }
      } else {
          AssemblyResult::Failed  // Lead broke, pieces fell, must retry
      }
  }
  ```

**Educational Value:** Teaches stained glass craft, multi-step artisan process

**Fun Factor:** High-value luxury goods, church commissions, artistic expression

**Implementation:** Multi-stage crafting with failure points and quality variations

  ```rust
      // Check required tools for stage
      let required_tools = match carving.stage {
          CarvingStage::RoughingOut => vec![StonemasonTool::PointChisel, StonemasonTool::WoodenMallet],
          CarvingStage::Shaping => vec![StonemasonTool::ClawChisel, StonemasonTool::WoodenMallet],
          CarvingStage::Smoothing => vec![StonemasonTool::FlatChisel, StonemasonTool::WoodenMallet],
          CarvingStage::Detailing => vec![StonemasonTool::FineChisel, StonemasonTool::WoodenMallet],
          CarvingStage::Complete => return,
      };

      if !required_tools.iter().all(|t| tools.tools.contains(t)) {
          return;  // Missing tools
      }

      // Work speed affected by skill and stone hardness
      let base_speed = 1.0;
      let skill_modifier = mason_skill as f32 / 100.0;
      let hardness_penalty = carving.stone_type.hardness();

      let work_speed = base_speed * skill_modifier * (1.0 - hardness_penalty * 0.5);

      carving.time_remaining = carving.time_remaining.saturating_sub((dt * work_speed) as u32);

      if carving.time_remaining == 0 {
          // Stage complete, move to next
          carving.stage = match carving.stage {
              CarvingStage::RoughingOut => CarvingStage::Shaping,
              CarvingStage::Shaping => CarvingStage::Smoothing,
              CarvingStage::Smoothing => {
                  if carving.complexity > 0.5 {
                      CarvingStage::Detailing
                  } else {
                      CarvingStage::Complete  // Simple carvings skip detailing
                  }
              },
              CarvingStage::Detailing => CarvingStage::Complete,
              CarvingStage::Complete => CarvingStage::Complete,
          };

          // Set time for next stage
          carving.time_remaining = match carving.stage {
              CarvingStage::Shaping => (30.0 * carving.complexity) as u32,
              CarvingStage::Smoothing => (20.0 * carving.complexity) as u32,
              CarvingStage::Detailing => (40.0 * carving.complexity) as u32,
              _ => 0,
          };

          // Quality check at each stage
          let quality_roll = rng.gen::<f32>();
          let stage_quality = (mason_skill as f32 / 100.0) + quality_roll * 0.3;
          carving.quality = (carving.quality + stage_quality) / 2.0;  // Running average
      }
  }
  ```

## Domain Translation Patterns

### Pattern: Historical Tools → Game Requirements
**Approach:**
1. Identify essential tools from historical sources
2. Map to game tool items
3. Recipes require specific tools
4. Tool availability gates professions

**Example:**
```
# Historical: Luthier needs planes, chisels, mallet, gluepot
# Game: Luthier workshop requires these 4 tools to craft instruments
# Progression: Start with basic tools, acquire specialized ones
```

---

### Pattern: Material Selection → Quality Variation
**Approach:**
1. Historical material choices (spruce vs pine, marble vs limestone)
2. Map to quality/cost tradeoffs
3. Better materials = higher quality products
4. Luxury materials expensive, rare

**Example:**
```
# Historical: Spruce soundboards best for lutes, ebony fingerboards luxury
# Game: Spruce gives +10% sound quality, ebony adds +50 gold value
```

---

### Pattern: Multi-Step Processes → Crafting Stages
**Approach:**
1. Break historical process into discrete steps
2. Each step has skill check, tools, materials
3. Failure possible at each stage
4. Final quality = average of all stages

**Example:**
```
# Historical: Stained glass = design → cut → paint → fire → lead → assemble
# Game: 6-step process, each with success/fail, quality accumulates
```
