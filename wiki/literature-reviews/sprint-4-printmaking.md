## The Real Tech Tree (Historical Progression)

### Substrate Layer (enabler)
- Papyrus (3000 BCE) -> Parchment (200 BCE) -> Paper (105 CE China -> Europe 1390s)
- **Key:** Without cheap paper, printmaking doesn't pay. Paper mill is a prereq.

### Print Methods (3 tracks)
1. **Relief:** woodblock (868+) -> woodcut (1400s)
2. **Intaglio:** engraving -> etching (1400s, sharper detail)
3. **Movable type:** clay (1041) -> metal (1234) -> press (1450s)

### Scale Multipliers
- Woodblock: carve once, print many (limited by block wear)
- Movable type: reuse type, compose pages (huge scale)
- Printing press: mechanical force, speed
- Lithography: 1798, quick + cheap, mass public

## Design Proposals

### Tech Tree Structure (not linear - a web)
- **Substrate track:** papyrus -> parchment -> paper -> paper mill (required for printmaking)
- **Relief track:** carving -> woodblock -> woodcut prints -> colored prints
- **Intaglio track:** metalworking -> engraving -> etching -> fine prints
- **Type track:** writing -> clay type -> metal type -> type foundry -> printing press -> mass production
- **Litho track:** chemistry -> lithography -> chromolithography (modern)

### Emergent Outcomes
- **Mass-market emerges first:** playing cards + devotional images (not books) - matches Met finding
- **Science accelerates:** herb/anatomy/engineering diagrams spread knowledge faster
- **Image democratization:** prints reach poorest members of society
- **Multiple viable paths:** relief for bulk, intaglio for quality, litho for speed/cost

### Mechanics
- **Paper mill is the gate:** printmaking techs locked until cheap paper exists
- **Method choice matters:** woodblock (cheap, crude), intaglio (detailed, slow), litho (fast, mass)
- **Market demand:** early prints sell as cards/devotionals, later books/science
- **Type reusability:** movable type's real innovation - compose once, reset, print different

## Rating
**Critical** - The tech tree should be a web, not a line. Paper mill is the true enabler, multiple print methods coexist with different outputs/markets, and mass-market images (cards) preceded books.
