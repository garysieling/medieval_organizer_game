## Summary

- **Event camera (#664):** a civic event the viewing seat is part of now rides the wire as `UiModel.player_event` — an `EventFocusV` (`epoch`, `kind`, `pos`, `extent`, `moving`, all `#[serde(default)]`-safe) that names the instance once and tracks it after.
- **Detection is seat-scoped:** `player_event_at` reports only what the seat called — a `FormationKind::March` the seat owns (kind 0, the column's live head as `pos`, `moving: true`) outranks a `Meeting` it called (kind 1, the venue tile, `moving: false`). Parades and funerals stay out: they're the village's, not the seat's errand.
- **Instance stamps:** `Formation.born` and `Meeting.born`/`venue` give each event its own epoch (`born * 4` for marches, `born * 4 + 1` for meetings — parity keeps the kinds from ever colliding), so the client jumps once per event, not every frame.
- **Client `EventCam`** (`view.rs`): a new epoch jumps the camera to `camera_on(pos)` and pulls zoom out via `event_zoom` — fit-the-extent, only ever zooming *out* (`current.min(fit)`), clamped to the shared `MIN_ZOOM`/`MAX_ZOOM` the bin's local consts now alias. A live event eases toward its centre at 0.15/frame — no hard cuts, no jitter.
- **Manual input wins briefly:** every camera-mutating input in `game_ui` (minimap drag, edge scroll, arrow keys, scroll/`+`/`-` zoom, search Enter, log/toast/mystery jumps) sets `manual_cam`, which holds the event camera off for `EVENT_HOLD` (240 frames) — pan wins for a spell, then the event has it back. A *new* event always jumps, hold or no hold.
- **Coexists with what was there:** intro `focus` and `camera_follow` run before `EventCam::step` each frame; an absent `player_event` resets the state so the next event reads as new.
- `docs/protocol.md` documents the field.
